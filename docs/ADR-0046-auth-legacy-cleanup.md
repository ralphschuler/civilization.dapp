# ADR 0046: WalletAuth-only browser access

Status: accepted (Issue #46, 2026-08-17). Owner: application team.

## Inventory and decision

| Path or surface                                                            | Owner                 | Status / decision                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------------------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/` → `WalletAccess` → `CivilizationClient`                                | application team      | Active. MiniKit WalletAuth obtains a one-time nonce, verifies SIWE, then renders the game on the same page.                                                                                                                                                                                                                                                                                                                        |
| `/api/wallet-auth/nonce`, `/api/wallet-auth/verify`                        | application team      | Active. The mutating nonce `POST` and verify `POST` use PostgreSQL-backed, single-use challenges, shared client/global budgets, and `no-store`; `429` includes `Retry-After`. Client identities are HMAC-hashed and forwarded source headers are used only under the explicit trusted-proxy deployment contract. Invalid input/nonce/signature returns a non-success JSON response, while database/configuration failure is `503`. No session, cookie, or redirect is issued. |
| `WALLET_AUTH_URL`, `WORLD_APP_ID`, contract/token/chain values, PostgreSQL | application team      | Active runtime inputs. `WALLET_AUTH_URL` binds SIWE to the Mini App origin.                                                                                                                                                                                                                                                                                                                                                        |
| Auth.js/NextAuth credentials and `/api/auth/*`                             | application team      | Removed. The former login ticket bridge and its table are retired by migration `004`; old migrations remain immutable migration history.                                                                                                                                                                                                                                                                                           |
| External proof browser registration and signing runtime inputs             | application team      | Removed. There is no frontend proof request or signing endpoint.                                                                                                                                                                                                                                                                                                                                                                   |
| `/game` protected navigation                                               | application team      | Removed. It could only redirect and must not become a second access path.                                                                                                                                                                                                                                                                                                                                                          |
| Deployed World ID methods, proxy storage, deployment scripts               | contract/release team | Explicit compatibility. They remain because the published proxy ABI/storage and preflight verification depend on them; they are not imported by the active game ABI/client. `CIVILIZATION_WORLD_ID_COMPATIBILITY_ABI` documents the isolation. Review by 2026-11-17; target removal is the next separately approved proxy upgrade, no earlier than 2026-12-31, after confirming no deployed ABI or storage consumer remains. |

`src/auth/siwe-binding.js` is the active, strict origin/version/chain binding for the server-side SIWE result. WalletAuth is UI address binding only; `registerWallet()` and every game mutation remain separately signed and authorized by the deployed contract. No contract or proxy change is part of this ADR.
